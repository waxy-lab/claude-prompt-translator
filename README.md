# Claude 英文提问助手

在 Chrome 原生侧栏写中文，使用 Chrome Translator API 在本机翻译，检查并修改英文后，明确点击填入 Claude 输入框，最后由你手动发送。

版本：0.1.1，个人本地加载版。原生 HTML/CSS/JavaScript，无运行时第三方依赖、云翻译、密钥或后台服务器。

从 GitHub 获取源码时，下载并解压仓库 ZIP，或克隆仓库，然后直接加载包含 `manifest.json` 的项目根目录即可；`dist/` 为本地生成目录，不随 Git 源码提交。如需单独的安装包，运行 `python tools/package.py` 生成。

**验证程度：30 项逻辑测试与隔离 Chrome 中 6 个页面夹具场景通过。0.1.1 修正输入框定位后，用户已于 2026-10-27 确认真实 Claude 页面功能能正常使用；这是用户实用反馈，开发方未独立重复真实页面端到端测试。** 详见 [TEST_REPORT.md](TEST_REPORT.md)。

## 安装

1. 使用桌面版 Google Chrome。清单最低版本为 138，但版本号不代表 API 或语言包实际可用；以侧栏提示为准。无需修改实验开关。
2. 使用交付目录 `dist/claude-english-assistant`，或解压 `dist/claude-english-assistant-0.1.1.zip`。
3. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择**直接包含 manifest.json 的文件夹**。ZIP 需要先解压。
5. 打开 `https://claude.ai/` 并进入聊天页，点击工具栏中的扩展图标；未显示时可在拼图菜单中找到“Claude 英文提问助手”。

无需运行 npm、Python 或构建命令即可加载交付目录。项目根目录也可加载，但推荐使用 dist 中只包含运行文件与说明的干净目录。浏览器不会安装 ZIP 本身。

### 已安装 0.1.0 的更新方法

先复制保留需要的中文和英文（重新加载扩展会清空会话草稿），在 `chrome://extensions` 找到本扩展，点击卡片上的圆形刷新按钮“重新加载”，确认版本显示 0.1.1。若原来加载的就是本项目 dist 目录，无需重新选择文件夹。回到 Claude，重新点击工具栏图标，重新输入/翻译后尝试填入。

## 使用

1. 在侧栏输入中文，选择简体或繁体，再点击“翻译成英文”。首次使用可能需要 Chrome 下载语言包。
2. 对照原文检查英文，尤其是代码附近的说明、技术术语和否定句。英文结果可以编辑。
3. 点击“填入 Claude”。网页已有文字时，先显示“替换现有草稿 / 取消”。确认有效期为 60 秒。
4. 到网页核对输入框，再由你手动发送。扩展不点击发送，不模拟回车发送。

可以随时取消翻译；迟到结果会被丢弃。取消不保证停止 Chrome 自身的语言包下载。模型初始化等待上限为 120 秒，正文翻译等待上限为 60 秒，超时保留原文与上次可见结果。

原文改动后，即使随后改回原样，也必须重新翻译。仅编辑英文不使已有有效译文失效。翻译失败、取消或重新翻译未完成时，旧结果仍可复制，但不能直接填入。填入检查进行期间暂时锁定编辑，避免源草稿变化后仍写入旧结果。

“复制英文”独立于网页填入。若 Chrome 不允许自动复制，会选中英文，按 Ctrl+C 即可。定位失败、权限丢失或发生冲突时，可以复制后手动粘贴。

## 草稿与隔离

- 草稿仅写入 `chrome.storage.session`，按**标签页 ID + 完整页面地址**隔离；不写入网页存储、同步存储或持久历史。
- 同次浏览器会话内，关闭侧栏再打开、刷新同一路由、切换会话再返回，可恢复该页草稿。查询参数和片段不同也视为不同页面。
- 关闭标签页会清理其草稿；“清空”删除当前页的中文、英文及翻译状态。关闭整个浏览器、禁用或重载扩展后，不应期待恢复。
- 未绑定可操作 Claude 页面时，提供该窗口独立的临时草稿；它不会自动带入其他标签页或会话。需要转移时自行复制中文。
- 填入会核对浏览器文档身份、路由变化版本、活动标签页及可见编辑器。替换确认会在侧栏编辑、切换目标等操作后失效。

不要把临时草稿当长期笔记。浏览器崩溃、存储配额或保存失败可能造成丢失；保存失败会显示提示。

## 文本保护范围

支持的 Markdown 子集：反引号/波浪线围栏（至少三个，结束围栏长度不小于开始）、成对行内反引号（含多个反引号）、HTTP/HTTPS/FTP/mailto/www 地址、单行 Markdown 链接目标及可选标题、单行引用式链接定义。片段直接原样重组，不依靠翻译占位符。换行、正文前后空白及常见标题/列表/引用前缀保留。

正文在代码和链接边界处分段，并按行翻译；分段可能降低上下文质量。纯英文或只有受保护代码的草稿原样显示，不初始化翻译引擎。

- 未闭合围栏从开始处到文末全部保留，并提示。
- 未闭合行内代码、未闭合或跨行链接目标、缩进代码块会明确拒绝翻译。请补齐或改为围栏代码。
- 尖括号片段原样保留并提示；不解析完整 HTML、复杂嵌套、表格、数学公式、MDX 或所有 Markdown 方言。重要的技术片段请主动加代码围栏。
- 裸 URL 建议与正文用空格分隔。中文句读标点用于分隔裸 URL；URL 包含这类标点时，请改用 Markdown 链接或行内代码。
- 上限 12,000 个 Unicode 码点（单个 emoji 计一个；组合 emoji 可能计多个）。超限不截断、不自动分批发送。

## 常见问题

**引擎不可用或下载失败**：点击“重新检查”，确认 Chrome 更新和语言包下载网络条件，也可更换简体/繁体语言对。设备、地区、Chrome 企业策略或模型准备条件可能限制可用性；不会改用云翻译。

**没有打开侧栏**：确认从 Chrome 扩展菜单选择了此扩展；尝试关闭已有侧栏再点击图标。报错时查看 `chrome://extensions` 中的错误。

**找不到输入框**：0.1.1 按 ProseMirror、Lexical、`chat-input` 等明确编辑器标识寻找可见且唯一的候选；带这些标识的编辑器不再要求 `main`/`form` 外层。仅有通用 textbox 角色时仍需要聊天主区域内的表单/fieldset。搜索区、侧栏、弹窗、已知文档/Artifact 区和多候选会被拒绝，不会退回到任意 contenteditable。若仍失败，提示会区分“匹配 0 个”与“多个编辑器”；保留提示，复制英文手动粘贴。用户已确认当前真实页面可正常使用，后续 Claude 页面更新仍可能需要适配。

**授权失效或页面变化**：回到目标 Claude 标签页，再点工具栏图标以授予 activeTab 临时权限，重新点击填入。跨站导航、会话变化或确认后草稿变化会阻止旧请求。

**无法确认填入成功**：先看网页输入框，避免重复粘贴。写入后会检查纯文本一致，但不能证明 Claude 内部状态一定同步；不会自动重试或回滚。contenteditable 使用封装的已弃用 `execCommand('insertText')`，真实兼容性必须另行验证。

## 权限与数据边界

仅申请 `sidePanel`、`activeTab`、`scripting`、`storage`，无常驻站点权限、cookies、debugger、网络拦截或历史记录权限。只允许 HTTPS 且主机严格为 `claude.ai`。侧栏可见时检查当前标签页身份元数据，不读取对话历史；只有填入操作才定位编辑器。已有网页草稿仅在页面隔离脚本中短时用于冲突检查，不回传侧栏。消息中的文字仅是明确点击填入的最终英文，不包含侧栏中文草稿字段。

不加载远程脚本，不收集分析事件，不编写草稿上传请求。Chrome 自身下载与遥测、Claude 网页本身的网络行为不属于扩展可控制范围。填入后内容已进入 Claude 网页；侧栏隔离不等于系统级保密，不承诺规避审核、隐藏扩展或避免账号限制。

## 开发与复验

运行逻辑测试（Node.js 22 或更新版本，无需 npm install）：

```powershell
npm test
```

浏览器页面夹具验证（使用本机已有 Playwright，不安装新依赖；请求全部拦截为本地 HTML，不访问真实 Claude，也不使用日常配置）：

```powershell
$env:PLAYWRIGHT_MODULE = '你的现有 Playwright 包绝对路径'
node tests/browser-fixtures.cjs
```

覆盖无表单的明确编辑器、显式替换、拒绝无标识输入区/搜索区、多候选、隐藏/文档区排除与确认后修改。结果在 `evidence/browser-fixtures.json`，不能替代真实 Claude 页面验收。

可选 Chrome Translator 探针需要本机现有 Playwright，**不属于扩展运行依赖**：

```powershell
$env:PLAYWRIGHT_MODULE = '你的现有 Playwright 包绝对路径'
node tests/feasibility.cjs
```

探针每次创建新的 `.validation/chrome-probe-*` 配置，只打开本机测试页，等待最多 60 秒后关闭测试浏览器，结果在 `.validation/feasibility.latest.json`。不能代替侧栏/Claude 验收。初版探针存在混合成功/失败记录；交付脚本已改为全新配置和单次请求，**改进版尚未再次运行**。

重新打包（Python 3 标准库）：

```powershell
python tools/package.py
```

打包使用明确文件清单，排除测试、浏览器配置和用户数据，不提交、推送、部署或发布商店。
