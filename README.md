# Claude 英文提问助手

在 Chrome 原生侧栏写中文，本机翻译成自然英文，核对后明确点击填入 Claude，由你手动发送。一次开启“自动中文阅读”后，当前会话的后续最新助手回复自动在侧栏显示中文。中文草稿和回复译文不写入 Claude 网页。

版本：0.2.3（第 3 轮待独立审查版），个人本地加载版。原生 HTML/CSS/JavaScript，无运行时第三方依赖、云翻译、密钥或后台服务器。

从 GitHub 获取源码时，下载并解压仓库 ZIP，或克隆仓库，然后直接加载包含 `manifest.json` 的项目根目录即可；`dist/` 为本地生成目录，不随 Git 源码提交。如需单独的安装包，运行 `python tools/package.py` 生成。

**验证程度：50 项逻辑测试、24 个 Chrome 本地页面场景及 8 组界面检查通过。0.2.3 将英文原文改为默认阅读排版，并整理“提问 / 阅读”分区；17 张公开夹具截图覆盖窄宽侧栏、浅深色与重要状态。扩展 API、模型及剪贴板在界面检查中为模拟；真实 Claude 新边界仍待复核。此前模型样例有改善，也仍有术语误译，不能保证所有文本正确。** 详见 [TEST_REPORT.md](TEST_REPORT.md)。

## 安装

1. 使用桌面版 Google Chrome。清单最低版本为 138，但版本号不代表 API 或语言包实际可用；以侧栏提示为准。无需修改实验开关。
2. 使用交付目录 `dist/claude-english-assistant`，或解压 `dist/claude-english-assistant-0.2.3.zip`。
3. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择**直接包含 manifest.json 的文件夹**。ZIP 需要先解压。
5. 打开 `https://claude.ai/` 并进入聊天页，点击工具栏中的扩展图标；未显示时可在拼图菜单中找到“Claude 英文提问助手”。

无需运行 npm、Python 或构建命令即可加载交付目录。项目根目录也可加载，但推荐使用 dist 中只包含运行文件与说明的干净目录。浏览器不会安装 ZIP 本身。

### 已安装旧版本的更新方法

先复制保留需要的中文、英文和回复译文（重新加载扩展会清空临时内容），在 `chrome://extensions` 找到本扩展，点击卡片上的圆形刷新按钮“重新加载”，确认版本显示 0.2.3。若加载的是本项目根目录或 dist 目录，无需重新选择文件夹；若解压到了别处，先替换为新版文件。版本没变化时，用“加载已解压的扩展程序”明确选择上述 dist 文件夹，避免重载另一份旧副本。回到 Claude，再点扩展图标并开启自动阅读。

## 使用

1. 在侧栏的“提问”分区输入中文，选择简体或繁体，再点击“翻译成英文”。首次使用可能需要 Chrome 下载语言包。
2. 对照原文检查英文，尤其是代码附近的说明、技术术语和否定句。英文结果可以编辑。
3. 点击“填入 Claude”。网页已有文字时，先显示“替换现有草稿 / 取消”。确认有效期为 60 秒。
4. 到网页核对输入框，再由你手动发送。扩展不点击发送，不模拟回车发送。

问题只做自然翻译，填入内容与英文预览一致；不添加“请用英文回答”、国籍、身份或语言偏好说明，也不强制 Claude 的回复语言。

### 填入前的中文检查

英文预览中的汉字、CJK 标点和全角字符会阻止填入，提示前五处行列位置；这也包括代码注释、路径、链接，以及手动编辑的结果。插件保留内容，不会为通过检查而静默删除、改写或编码。请自行核对并决定如何处理。

检查发生在发送任何填入消息之前，后台和最终写入模块另有保护。它是字符范围检查，不是完整语言识别：英文标点、其他语言或 Unicode 字符不一定被拦截；日文汉字也会被保守拦截。“复制英文”复制当前预览，手动粘贴不受网页写入检查保护。

### 自动中文阅读

1. 在已进入的 Claude 会话中，保持侧栏可见，切到“阅读”，点击一次“开启自动阅读”。首次使用英译中语言包可能下载，初始化最多等待 120 秒。
2. 开启后只读取当前已授权且活动标签页中最新的、明确标记的助手回复。后续新回复自动更新，无需逐条点击；通过“中文译文 / 英文原文”切换核对。
3. 流式回复优先取稳定段落，并至少等待一个 1.5 秒轮询间隔确认候选未变。不能可靠拆出稳定段落时等待；显示“稳定片段/快照”，不把中途结果标为完整回复。
4. 点击“暂停并清空译文”停止读取、取消任务、销毁实例和缓存。失败/超时后点击“重试自动阅读”；需要用户手势时只在开启/重试要求，不逐条要求。

自动阅读默认关闭，不保存开关。切换标签页/会话、刷新导航、权限失效、侧栏隐藏/关闭时停止并清空回复内存。回来后再点一次开启。`/new` 首次发送后可能跳到新会话地址，这也视为目标变化；建议首次发送进入会话后再开启。问题草稿继续按原 session 分区恢复。

实例在本次开启期间复用；相同正文片段使用总计最多 100,000 个 UTF-16 单元的有界内存缓存，避免逐 token 重译。回复上限 60,000 个 Unicode 码点，不截断；读取等待 10 秒，一次稳定快照翻译等待 60 秒。失败不发布本次半截结果。译文、英文回复和缓存不写 storage.session/local/sync 或网页存储。

中英文共用段落、标题、列表、行内代码和代码块的有限安全排版。英文默认“阅读”视图，不显示格式围栏；“文本”入口保留可核对的内部文本，“复制文本”始终复制该内部原文。它来自网页可见内容，不能视为 Claude 生成时的原始 Markdown。提取未保留的强调、引用层级不会凭空恢复。代码区保留语言名称和空白，可横向滚动并通过键盘聚焦；普通长 URL 换行，URL 以不可点击、可选择的文本显示，不加载外链资源。

“提问 / 阅读”和中英文、阅读/文本的切换只改变侧栏视图，保留草稿、译文及目标，已有自动阅读继续运行；顶部状态一直可见。主分区及语言标签支持方向键、Home/End，其他控件可用 Tab。确认替换、中文字符拦截或提问失败即使在阅读分区也有返回处理入口。真正的侧栏隐藏、页面导航和暂停仍按原规则停止并清空。

只创建文本节点和固定页面元素，不把模型输出解释为 HTML，不覆盖网页英文。提取时优先助手容器里的明确正文/Markdown 区，排除已识别的朗读摘要、推广、时间、用户输入、搜索、Artifact 和思考区域；识别不到时提示并等待，不回退扫描整页。Claude 原回复可能本身含中文，插件不改写网页原回复。

所有已支持的助手标记在同一候选集合中按页面顺序选择最新独立消息，嵌套标记去重，不再让旧的 role/testid 标记压过更新的字体类标记。代码旁的混合正文和按钮独立处理，不以“附近有代码且含按钮”为由删除正文。行内代码采用成对填充/解码契约：只去除序列化加入的一对格式空格，原有边界空白保留，全空格代码不裁剪。

可以随时取消翻译；迟到结果会被丢弃。取消不保证停止 Chrome 自身的语言包下载。模型初始化等待上限为 120 秒，正文翻译等待上限为 60 秒，超时保留原文与上次可见结果。

原文改动后，即使随后改回原样，也必须重新翻译。仅编辑英文不使已有有效译文失效。翻译失败、取消或重新翻译未完成时，旧结果仍可复制，但不能直接填入。填入检查进行期间暂时锁定编辑，避免源草稿变化后仍写入旧结果。

“复制英文”独立于网页填入。若 Chrome 不允许自动复制，会选中英文，按 Ctrl+C 即可。定位失败、权限丢失或发生冲突时，可以复制后手动粘贴。

## 草稿与隔离

- 草稿仅写入 `chrome.storage.session`，按**标签页 ID + 完整页面地址**隔离；不写入网页存储、同步存储或持久历史。
- 同次浏览器会话内，关闭侧栏再打开、刷新同一路由、切换会话再返回，可恢复该页草稿。查询参数和片段不同也视为不同页面。
- 关闭标签页会清理其草稿；“清空”删除当前页的中文、英文及翻译状态。关闭整个浏览器、禁用或重载扩展后，不应期待恢复。
- “清空”还暂停自动阅读并删除回复内存；回复不随问题草稿恢复。
- 未绑定可操作 Claude 页面时，提供该窗口独立的临时草稿；它不会自动带入其他标签页或会话。需要转移时自行复制中文。
- 填入会核对浏览器文档身份、路由变化版本、活动标签页及可见编辑器。替换确认会在侧栏编辑、切换目标等操作后失效。

不要把临时草稿当长期笔记。浏览器崩溃、存储配额或保存失败可能造成丢失；保存失败会显示提示。

## 文本保护范围

支持的 Markdown 子集：反引号/波浪线围栏（至少三个，结束围栏长度不小于开始）、成对行内反引号（含多个反引号）、HTTP/HTTPS/FTP/mailto/www 地址、单行 Markdown 链接目标及可选标题、单行引用式链接定义。片段直接原样重组，不依靠翻译占位符。换行、正文前后空白及常见标题/列表/引用前缀保留。

问题草稿仍采用代码/链接边界分段及按行翻译；纯英文或只有受保护代码的草稿原样显示，不初始化翻译引擎。

回复在 0.2.1 改为尽量整段翻译：代码、URL、常见技术标识先替换成不含原内容的标记，返回后要求每个标记精确存在一次、顺序一致且无额外标记，才原样还原。大小写变化、丢失、重复或重排都拒绝；失败则显示提示并退回分段翻译，不猜测对齐。被拒模板在有界缓存中记为失败，避免反复尝试同一坏模板。原代码和 URL 不送到模型，围栏代码块完全跳过模型。与原设计中避免脆弱占位符的初衷一致，这里不会信任未经校验的标记；新增整段通道是针对实测上下文丢失的受控改进。

这不会改变本地模型的能力上限；例如 memoization 在实测中仍被译为“备忘录”。语言名称如 Python 保留英文，避免字面误译为“蟒蛇”。请对照英文核对概念、否定句和专名；不强行全局替换自然语言词语来伪造翻译准确。

- 未闭合围栏从开始处到文末全部保留，并提示。
- 未闭合行内代码、未闭合或跨行链接目标、缩进代码块会明确拒绝翻译。请补齐或改为围栏代码。
- 尖括号片段原样保留并提示；不解析完整 HTML、复杂嵌套、表格、数学公式、MDX 或所有 Markdown 方言。重要的技术片段请主动加代码围栏。
- 裸 URL 建议与正文用空格分隔。中文句读标点用于分隔裸 URL；URL 包含这类标点时，请改用 Markdown 链接或行内代码。
- 上限 12,000 个 Unicode 码点（单个 emoji 计一个；组合 emoji 可能计多个）。超限不截断、不自动分批发送。

回复从 DOM 转成受限文本格式，不是取回 Claude 原始 Markdown：正文包装层不叠加空行，标题/列表保留语义，表格按单元格展开；链接显示为“文字 <原 href 属性>”，目标不重写。代码块的语言从元数据或已识别语言栏读取，不把复制按钮和语言栏当正文翻译；围栏代码的格式分隔换行与代码内容分开，渲染器保留原 DOM 代码缩进及内部空行。常见技术标识额外保护，但无法推断所有自然语言里的命令/专名。图片不读取，数学/画布等不支持结构明确报错，不以删除正文来返回成功。

## 常见问题

**引擎不可用或下载失败**：点击“重新检查”，确认 Chrome 更新和语言包下载网络条件，也可更换简体/繁体语言对。设备、地区、Chrome 企业策略或模型准备条件可能限制可用性；不会改用云翻译。

**没有打开侧栏**：确认从 Chrome 扩展菜单选择了此扩展；尝试关闭已有侧栏再点击图标。报错时查看 `chrome://extensions` 中的错误。

**找不到输入框**：0.1.1 按 ProseMirror、Lexical、`chat-input` 等明确编辑器标识寻找可见且唯一的候选；带这些标识的编辑器不再要求 `main`/`form` 外层。仅有通用 textbox 角色时仍需要聊天主区域内的表单/fieldset。搜索区、侧栏、弹窗、已知文档/Artifact 区和多候选会被拒绝，不会退回到任意 contenteditable。若仍失败，提示会区分“匹配 0 个”与“多个编辑器”；保留提示，复制英文手动粘贴。用户已确认当前真实页面可正常使用，后续 Claude 页面更新仍可能需要适配。

**授权失效或页面变化**：回到目标 Claude 标签页，再点工具栏图标以授予 activeTab 临时权限，重新点击填入。跨站导航、会话变化或确认后草稿变化会阻止旧请求。

**已有回复但没有中文**：检查是否已开启、目标是否变化，查看提示。目前只支持 `[data-message-author-role="assistant"]`、`[data-testid="assistant-message"]` 或 `.font-claude-response` 明确区域。新回复选择器尚未在本轮真实页面验证，结构不符时请提供提示，不会以整页读取绕过失败。

**无法确认填入成功**：先看网页输入框，避免重复粘贴。写入后会检查纯文本一致，但不能证明 Claude 内部状态一定同步；不会自动重试或回滚。contenteditable 使用封装的已弃用 `execCommand('insertText')`，真实兼容性必须另行验证。

## 权限与数据边界

仅申请 `sidePanel`、`activeTab`、`scripting`、`storage`，没有为自动阅读增加常驻站点权限、cookies、debugger、网络拦截或历史记录权限。只允许 HTTPS 且主机严格为 `claude.ai`。可见侧栏定期检查页面身份；开启阅读后每 1.5 秒最多进行一次最新回复的只读检查，不展开历史。暂停时已发出的单次检查可能完成，但结果丢弃，后续不再读取。

已有网页草稿只在填入时由隔离脚本短时检查，不回传侧栏。向网页的填入消息只含通过检查的最终英文和目标约束；读取消息只含类型和目标，回复单向从网页传回扩展。侧栏中文草稿、中文译文不经消息发给网页脚本，也不使用 MAIN world 注入。

不加载远程脚本，不收集分析事件，不编写草稿上传请求。Chrome 自身下载与遥测、Claude 网页本身的网络行为不属于扩展可控制范围。填入后内容已进入 Claude 网页；侧栏隔离不等于系统级保密，不承诺规避审核、隐藏扩展或避免账号限制。

## 开发与复验

运行逻辑测试（Node.js 22 或更新版本，无需 npm install）：

```powershell
npm test
```

浏览器页面夹具验证（使用本机已有 Playwright，不安装新依赖；请求全部拦截为本地 HTML，不访问真实 Claude，也不使用日常配置）：

```powershell
$env:PLAYWRIGHT_MODULE = '你的现有 Playwright 包绝对路径'
node tests/browser-fixtures.cjs
node tests/reading-browser.cjs
node tests/ui-browser.cjs
```

依次覆盖原有填入回归、回复读取与自动更新、界面交互与截图。结果在 `evidence/browser-fixtures.json`、`evidence/reading-browser-fixtures.json` 和 `evidence/ui-0.2.3.json`。截图索引记录每张 PNG 的尺寸、状态及 SHA-256；内容为公开夹具，扩展 API/Translator/剪贴板为模拟，不能替代真实 Claude 或剪贴板权限验收。

可选真实英译中检查：`node tests/model-readiness.cjs`。一次点击后用同一实例翻译两段公开样例，使用新的隔离 Chrome 配置和本机普通测试页，不访问 Claude。结果在 `evidence/local-model-0.2.0.json`，不代表扩展源内或真实会话端到端通过。

0.2.1 对比脚本为 `tests/quality-model.cjs`：需要完整的 0.2.0 交付目录作旧流程基线（可从本地旧 ZIP 解压），通过 `QUALITY_BASELINE` 指定其路径；`QUALITY_PROFILE` 仅允许指向本项目 `.validation` 内生成的隔离配置。旧/新流程经适配器共享同一枚真实模型，不能当作两个模型独立初始化或质量基准测试。结果在 `evidence/quality-model-0.2.1.json`；初始化失败和最初保护标记失败的过程也保留，见测试报告。

可选 Chrome Translator 探针需要本机现有 Playwright，**不属于扩展运行依赖**：

```powershell
$env:PLAYWRIGHT_MODULE = '你的现有 Playwright 包绝对路径'
node tests/feasibility.cjs
```

探针每次创建新的 `.validation/chrome-probe-*` 配置，只打开本机测试页，等待最多 60 秒后关闭测试浏览器，结果在 `.validation/feasibility.latest.json`。不能代替侧栏/Claude 验收。初版探针存在混合成功/失败记录；交付脚本已改为全新配置和单次请求，**改进版尚未再次运行**。

重新打包（Python 3 标准库）：

```powershell
python tools/package.py
```
